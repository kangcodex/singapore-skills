# Visual liveability and exact-home mapping

Inspect the actual drawings visually when tools allow; combine text, dimensions
and drawings. Record document/page/version and whether rendering succeeded. If
only extracted text is available, give a text-based assessment and the visual gap.

Check bedrooms with beds/desks/wardrobes, doors/access, windows/ventilation,
circulation, kitchen/worktop/cooking, dining, laundry, storage, service/shelter/
yard/WC, balcony allocation, accessibility and parking. Explain everyday effects.
Furniture examples are illustrative; do not infer clear internal dimensions from
stylised drawings or assume doors/walls/structural constraints can be changed.

## Fixed reasoning fixtures

- A 732 sqft study reached through the master suite has access/privacy limitations;
  it is not an independent common bedroom.
- A 775 sqft study accessed from common space may improve shared access but can
  still lack enclosure, windows or bedroom suitability.
- A 1,055 sqft Premium plan with storage and yard/WC can add household utility
  over 947 sqft without every extra sqft enlarging bedrooms.

These are historical/synthetic evaluation conditions, not refreshed project facts.
Require the actual matching plans before visually certifying an extraction.

For blocks verify layout/type → block → stack → floor → unit, including mirrored,
PES and special-level variants. For landed verify address/parcel/title and floor/
section mapping. Record orientation from a reliable north reference, access points,
facing distances, service/road/facility adjacency and future obstruction evidence.

Do not attach project starting prices or area×PSF scenarios to a stack. A highlighted
stack without exact quote is a layout/location candidate, not proven best value.
No rendered view/floor evidence means no guaranteed clearance or best-floor claim.
Separate best household layout, best evidenced outlook, best value at a quoted
price and best overall fit. Annotate sources and advisor marks distinctly.
