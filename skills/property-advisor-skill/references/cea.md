# Optional salesperson verification

The historical `--verify-salesperson` flag queries the bundled shared client's
CEA directory source. A unique match returns registration number, name, recorded
status and agency. Empty/no-match/failed/ambiguous results remain null; an ambiguous
name must not verify the first person returned. Ask for an exact registration
number before drawing an identity conclusion.

Source publication frequency is not a guarantee of retrieval freshness. The
legacy shared cache does not reliably expire; do not represent its cached status
as verified within hours. Use current official CEA evidence and retain the source
and dates when registration matters to the buyer's action. No match is not proof
that a person is unregistered or inactive.

Directory identity, transaction history and suitability as an agent are different
questions. This lookup does not establish competence, provide an endorsement or
authorize contacting/sharing buyer details. Preserve the user's explicit outreach
authority and disclose any referral relationship separately.
